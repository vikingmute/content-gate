## Pre-Publish Checklist

Copy checked items from the skill. Section 6 should be mostly Yes.

**Helpfulness**

- [ ] Direct visitor would find it useful
- [ ] Reader can complete a concrete goal
- [ ] First-hand traces exist
- [ ] Extra value beyond restating docs or competitors
- [ ] Title is accurate, not hype
- [ ] Would share or bookmark it

**Trust**

- [ ] Attribution / ownership is clear
- [ ] Trust surfaces reachable
- [ ] Key facts verified by a human who knows the topic
- [ ] No easily checkable exaggerations or stale claims
- [ ] AI-assisted drafts were deeply edited

**Craft & localization**

- [ ] Written for the target language’s readers first
- [ ] Plain, specific, actionable verbs
- [ ] No empty marketing fluff
- [ ] No mechanical keyword repetition
- [ ] Product/topic boundaries stated honestly
